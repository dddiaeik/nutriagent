# NutriAgent V1.4 UI 디자인

대화 영역은 식사 계산과 후보 비교에 집중하고, 사이드바에서는 오늘의 목표 달성률과 확정 기록을 관리한다. 보조 기능인 목표 입력, 기록 수정·철회, 원본 식품 목록, 시스템 정보는 필요할 때 펼친다. 넓은 화면에서는 본문과 하단 입력창을 최대 1,120px에 맞추고, 좁은 화면에서는 Streamlit 사이드바 토글을 사용한다.

## 색상과 글꼴

| 역할 | 색상 |
| --- | --- |
| 기본 행동과 브랜드 | `#287D5A` |
| 강조 배경 | `#EAF5EF` |
| 화면과 카드 | `#F7F9F8`, `#FFFFFF` |
| 기본·보조 글자 | `#18241E`, `#526158` |
| 테두리 | `#D9E4DE` |
| 미기록 상태 | `#744B13` 글자와 `#FFF5DF` 배경 |

Streamlit의 sans-serif 설정과 장치의 한글 글꼴을 사용한다. 목표 카드와 합계 카드는 고정폭 숫자 기능을 적용한다. 소수점 이하는 표시할 때 다듬고 계산값은 유지한다. 상태는 색과 함께 텍스트로 표시한다.

## 주요 컴포넌트

- **목표 대시보드**는 확정량을 기준으로 설정한 목표량, 남은 양 또는 초과량, 퍼센트, 진행 막대를 표시한다. 초과 비율은 텍스트에 그대로 표시하며 막대는 100%에서 멈춘다.
- **영양 합계와 세부 표**는 열량을 강조하고 4개 영양소를 나란히 배치한다. 좁은 화면에서는 합계는 2열, 식품별 표는 음식별로 쌓이는 형태여서 식품명과 단위를 함께 읽을 수 있다. 식품 코드는 해당 응답의 **식품별 출처와 코드**에서 확인한다.
- **기록 상태**는 계산 완료·미기록, 기록 완료, 수정, 취소, 추천 후보를 구분한다. 최근 미기록 응답에는 주 버튼을 제공한다. 오래된 응답에도 기록 버튼과 상세 화면 접근을 유지한다.
- **추천과 대체**는 후보를 만들었을 당시의 목표 차이를 비교한다. 대체 전후 음식과 중량, 영양소 증감도 함께 보여 준다.
- **모드와 준비 상태**는 모델이 선택된 것과 연결을 확인한 것을 구분한다. Ollama는 확인 버튼을 눌렀을 때 모델 목록만 조회한다. 영양 가이드 검색은 PDF에서 추출한 원문과 페이지를 제공한다.

## 파비콘과 적용 범위

시안 A는 녹색 라운드 타일 위에 흰 잎과 굵은 체크를 넣었다. 시안 B는 타일 없이 녹색 잎 실루엣에 흰 체크를 넣었다. 밝고 어두운 배경에서 두 시안을 16·32·48px로 비교한 결과, 16px에서 흰 잎과 체크의 경계와 전체 모양이 더 잘 구분되는 A를 선택했다.

`assets/nutriagent.svg`에 선택본을, `assets/nutriagent-leaf.svg`에 시안 B를 보존한다. Streamlit 1.51.0의 브라우저 파비콘과 채팅 아바타에는 선택본에서 파생한 64px 투명 PNG를 사용한다. 브라우저에서 실제 PNG 파비콘 제공을 확인했다.

공식 Streamlit 테마, 컨테이너, 채팅, 버튼을 사용한다. 목표 카드와 응답 표는 접근성 이름을 포함한 HTML 요소로 표시하며 CSS는 자체 클래스와 위젯 키 기반 클래스에 적용한다. 사용자 스크롤을 처리하는 JavaScript나 별도 프런트엔드 의존성은 추가하지 않았다. 모바일 사이드바의 기본 오버레이와 시스템 메뉴는 Streamlit 동작을 따른다.
