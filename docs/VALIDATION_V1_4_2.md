# V1.4.2 검증 기록

## 사용자 제공 V1.4.1 기준

원본 RTX 로그는 이 환경에서 확인할 수 없었으며 아래는 사용자 제공 요약이다.

| | Qwen3:8B | Qwen3.5:9B |
| --- | ---: | ---: |
| 엄격한 통과 | 33/45 (73.33%) | 42/45 (93.33%) |
| 평균 Agent 처리 | 1.540초 | 2.093초 |
| Warm 평균 처리 | 1.118초 | 1.768초 |
| 평균 출력 생성 | 73.38 tok/s | 61.63 tok/s |
| 평균 입력 토큰 | 1,095.2 | 1,266.0 |

Qwen3:8B에서 `swap`, `swap-split-keep`, `ambiguous-swap`, `swap-old-weight`가 반복 실패했다. Qwen3.5:9B에서 `ambiguous-swap`이 반복 실패했다. 당시 실패 전체에 대해 최종 영양 결과가 기록되지는 않았으므로 보정 후 실행 정확도는 미검증이다.

## V1.4.2 검증

- 기준 브랜치와 PR #6의 헤드에서 V1.4.1의 85개 오프라인 테스트가 통과했다. 실추론 두 테스트는 기본 검증에서 건너뛰었다.
- 최종 오프라인 검증은 기존 85개와 신규 19개가 모두 통과했다. 신규 검증에는 LEGACY 프롬프트·스키마 고정, SPLIT 필수 인수, 보정 및 차단, 확정 기록 보호, 데이터셋 대조, 누락 및 실패 집계, 성능 계산, 반복 일관성을 포함한다.
- Linux Chromium의 두 모드에서 식사 저장, 중량을 지정한 대체, 확정 기록 불변, PDF 출처 링크를 검증했다.
- K-FIND 워크북 SHA-256과 식품 98종의 원본 값 일치 여부는 기존 원본 검증 스크립트로 확인했다. USDA·K-FIND 추출 파일, 원본 PDF 해시, 영양 계산 및 추천 엔진은 변경하지 않았다.
- 기본 실행 경로와 실험 경로의 실제 모델 검증은 클라우드의 Ollama 연결 단계에서 막혔다. 기존 180건과 신규 216건의 사전 점검은 모두 연결 오류로 기록되었다. JSONL, 메타데이터, 세 요약과 ZIP 출력은 확인했다. 비율과 성능은 null로 남겼다.

RTX 2080 SUPER에서 [평가 프로토콜의 PowerShell 명령](EVALUATION_PROTOCOL_V1_4_2.md#실행)으로 같은 설정을 검증한 뒤 채택 여부를 판단한다. 이 단계에서 100% 목표 달성이나 SPLIT 채택은 미확정이다.
